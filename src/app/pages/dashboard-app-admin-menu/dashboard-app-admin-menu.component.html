Menu Management Help
1. Hide Some Menus for App Admin and Show Only Few for Regular User
  1. Open Master Menu and click Edit for a menu item.
  2. In Role Active Map, use role checkboxes to control visibility per role.
  3. To hide for App Admin: uncheck ROLE_ADMIN, keep other roles checked if needed, then Save.
  4. To show only few menus for regular users: for only the allowed menu items, keep ROLE_USER checked; for all other items, uncheck ROLE_USER and Save.
  5. Repeat for each menu item until the Regular User role is enabled only on required items.
  6. Add Reason before save for audit tracking.
  7. Verify quickly:
    • Use the Roles filter input in the table header to type Admin or User (filters apply automatically).
    • Check the Roles column in table to confirm final visibility mapping.
App Admin Tasks (Detailed)
  1. Create menu items with Item Key, title, route, icon, section, and sort order.
  2. Show/Hide by role using Role Active Map checkboxes in the edit form. One menu item can be enabled for multiple roles.
  3. Attach to subscription plan using the Min Plan field. Use the Subscription header filter to quickly search matching items.
  4. Control release behavior with Status (Show/Hide), Status Key, and Locked View handling.
  5. Enterprise-specific behavior is managed in Enterprise Overrides where visibility/lock can be updated per enterprise.
Adding a Menu
  1. Click the Add Menu button at the top right.
  2. Fill in all required fields in the drawer form.
  3. Click Save to create the new menu item.
Filtering
  1. Use the filter inputs in the table header row (one per column).
  2. Type in any column to filter results. Filtering applies automatically after a short delay.
  3. Use the Roles filter to search by role label (Admin / User / Ent Admin / Ent Emp).
  4. Use the Subscription filter to search by plan name.
Editing a Menu
  1. Click the Edit icon on the desired row.
  2. The edit drawer will open on the right.
  3. Update the fields as needed and click Save.
Clearing Filters
  1. Click the X icon on the right side of a column header to clear that filter.
  2. To clear manually, delete the text in the filter input.
